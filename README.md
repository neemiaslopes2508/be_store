# Bê Store

Landing page estática e responsiva para a Bê Store.

## Visualização

Abra `index.html` no navegador. Não é necessário instalar dependências nem executar um build.

## Conteúdo

- Os botões de contato e as categorias levam ao Instagram oficial `@_usebestore`.
- As fotos de semijoias são imagens editoriais ilustrativas, não fotografias do estoque real.
- A logo em `assets/be-store-logo.png` é a imagem enviada pela marca.

Para atualizar textos, links ou categorias, edite `index.html`. Os estilos estão em `styles.css` e o menu para celular em `script.js`.
